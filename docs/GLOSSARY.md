# Glossary in plain words

| Term | What it means |
| --- | --- |
| **Ad spend** | Money paid to run advertising. |
| **Channel** | A place ads run, for example a search engine, a social network or a streaming service. |
| **Campaign** | One advertising effort inside a channel. |
| **Return per $1** (ROAS) | Sales created for each $1 of ad spend. 3.00x means $3 of sales for every $1. |
| **Breakeven** | The return at which the ads just pay for themselves. With no margin entered it is 1.00x. With a 50% profit margin you need 2.00x. |
| **Platform reported** | What the ad platform says its ads delivered. Platforms mark their own homework, so this tends to run high. |
| **Attribution model** | A method that shares credit for each sale across the ads a customer saw. Better than platform reports, but still an estimate of credit, not proof. |
| **Holdout test** (control test) | Some cities keep seeing ads, similar cities do not, and the difference shows what the ads caused. |
| **Proven return** | The return measured by the controlled test. |
| **Claimed but unproven revenue** | Sales the platforms take credit for that the tests do not support. |
| **Spend not earned back** | Ad spend that the proven sales did not repay. |
| **Counting basis** | Which way of counting to lead with: all revenue in the test cities (simple, looks better) or only the extra revenue the ads caused (strict, safer). Both are always calculated. |
| **95% likely range** | We are 95% sure the true figure sits inside this range. A narrow range means a precise result. |
| **Statistically significant** | The result is clearly more than zero and is unlikely to be luck. |
| **Confident, Leaning, Not yet reliable** | The three evidence levels. Confident results are strong enough to act on. Leaning results point one way and need more testing. Not yet reliable results cannot be approved. |
| **Guardrail** | A rule that watches results and raises a concern, for example "money not earned back". |
| **Risk appetite** | How cautious the guardrails are: Conservative, Balanced or Aggressive. |
| **Advisory council** | Four advisors who read the same results from different business angles. |
| **Decision packet** | A one page proposal that a person approves, changes or rejects. |
| **Signed decision record** | A permanent list of signed decisions in which each entry is linked to the one before, so tampering is visible. |
| **Synthetic data** | Made up data that behaves like real data. Used here so results are repeatable and no real company is involved. |
| **Hand off** | Recording that an approved change is ready for the team that makes it. In this project nothing is sent anywhere. |
| **Audience tier** | A group of people ranked by how likely they were to buy even without seeing an ad. Tier 1 is the most likely buyers (for example past visitors), Tier 3 is a broad audience. |
| **Sales that would have happened anyway** | Revenue a platform credits to ads that the comparison with control markets shows would have arrived without them. Analysts call this cannibalization. |
| **Spend paying for sales that would have happened anyway** | The part of a tier's spend that bought those sales: spend times the share of credited sales the ads did not cause. |
| **Share caused by ads** (lift) | How much higher the conversion rate is in the test markets than in the matched control markets, as a share of the test rate. |
| **Control market match** | How well the markets that did not see the ads resemble the test markets, in past sales and in the mix of people. Reported as Match passed or Review required. |
| **Audience mix overlap** | How closely two sets of markets have the same share of residents in each likelihood to buy group. 100% means identical. |
| **Not enough data** | A tier with too few people or conversions to judge. It never raises a recommendation. |
